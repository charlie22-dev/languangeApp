# Noto Sans JP

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp

`NotoSansJP.ttf` is the unmodified variable font `NotoSansJP[wght].ttf`, renamed
only for a simple asset path. It provides offline Japanese fallback glyphs and is
registered as `NotoSansJP` in pubspec.yaml. See `NotoSansJP-OFL.txt` for its SIL
Open Font License; the app also registers that license on the Licenses screen.
