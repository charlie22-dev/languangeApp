# Optional bundled pronunciation clips

Put licensed word/phrase recordings here (for example `hello.mp3`) and set the
word or exercise JSON `audioUrl` to `assets/audio/hello.mp3`.
This folder is registered in pubspec.yaml. No sample voice recordings are
bundled; the Japanese course uses the configured `ja-JP` TTS voice by default.
Use HTTPS URLs for remote recordings; they are cached when played.
